# Financial AI Agent Assistant

Capstone for the *Agentic AI for Finance* course. A multi-modal RAG pipeline and agent that answers analyst-style questions over filings, fund documents, CSVs, news and analyst ratings, with every figure traceable to its source.

**Status:** design phase. Phase 0 will scaffold the Python AI engine and the Jupyter notebooks that wrap it.
